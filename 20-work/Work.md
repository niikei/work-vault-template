# Work

現在の仕事に関するノートと資料を置く。下位の名前・粒度・深さは自由である。

```text
20-work/
  新製品A/
  認証基盤刷新/
  〇〇部共通/
  新入社員研修/
```

プロジェクト・部署・業務領域・人物・研修などが混在してよい。入れ子も自由である。フォルダは固定データモデルではなく、人間向けの可変な置き場所である。

1ファイルで始め、関連ファイルが増えたら同じ場所でフォルダ化する。分類を先回りしない。

概要ノートは必要な場合だけ、フォルダと同じ名前で作る。

```text
新製品A/
  新製品A.md
  20260803_仕様確認.md
  assets/
```

フォルダを越えた関係はMarkdownリンクで表す。所属を`project`や`area`としてYAMLへ重複させない。
